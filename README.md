## Deskripsi
Website untuk mengelola tantangan pembelajaran harian atau mingguan bagi siswa. 
Sistem ini membantu guru dalam memberikan tantangan secara terstruktur serta memantau progres pengerjaan siswa secara sederhana.

## Permasalahan
Motivasi belajar siswa sering menurun karena kurangnya aktivitas pembelajaran yang ringan namun konsisten. 
Guru juga kesulitan memantau tantangan yang sudah dikerjakan siswa dan progres belajar mereka.

## Fitur
- CRUD tantangan
- Sistem pengerjaan tantangan oleh siswa
- Status/progress pengerjaan
- Riwayat tantangan
- Login dan logout
- Profile

## Teknologi
- PHP
- MySQL
- MVC
- Tailwind CSS

## Cara Menjalankan
1. Import database .sql
2. Jalankan Laragon/XAMPP
3. Buka localhost/project
